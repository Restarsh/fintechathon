# Security Policy

## Scope

StudentPay AI is an educational prototype. It does not execute real payments or connect to financial institutions.

## Reporting a vulnerability

Do not publish passwords, personal data, API keys, or exploit details in public issues. For a real deployment, establish a private security-reporting contact before accepting external users.

## Current limitations

- Authentication and session handling are basic and are not production-grade.
- MFA, account recovery, and email verification are not implemented.
- Login throttling is basic and is not designed for multi-instance deployment.
- Database encryption is not configured.
- Live provider verification, live FX data, payment APIs, and AI integration are not implemented.
- No independent penetration test has been performed.

Do not use this prototype to store real financial credentials or process actual transactions.
